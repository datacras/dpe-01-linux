🧠 Hissə 1 — Nəzəri Suallar Sessiya 00 · 20 xal

Aşağıdakı suallara öz sözlərinizlə cavab yazın. Hər cavab 3–5 cümləlik olsun. Kopyala-yapışdır qəbul edilmir.

1

Əməliyyat sistemi nədir? Asan

Əməliyyat sisteminin rolunu öz sözlərinizlə izah edin. İstifadəçi, ƏS və hardware arasındakı əlaqəni bir nümunə ilə göstərin.

★ AI Tip: Cavabınızı yazdıqdan sonra Claude-a verin: "Bu izahatı oxu və 3 nöqtədə daha yaxşı edə biləcəyimi söylə"
2

Binary (0/1) — niyə lazımdır? Asan

Kompüterin niyə yalnız 0 və 1 anladığını izah edin. İnsan dili ilə kompüter dili arasındakı fərqi göstərin.

3

Client OS vs Server OS — fərq nədir? Asan

İki növü müqayisə edin. Ən az 4 fərqli cəhəti cədvəl və ya siyahı şəklində yazın.

4

Linux niyə server dünyasını domine edir? Orta

Linux-un server mühitlərində (AWS, Google, Facebook, bank sistemləri) bu qədər geniş yayılmasının ən az 5 səbəbini açıqlayın.

5

Hypervisor Tip 1 vs Tip 2 — nə zaman hansını seçirik? Orta

İki hypervisor tipini müqayisə edin. Hansı ssenarilərdə Tip 1, hansı ssenarilərdə Tip 2 seçilir? Nümunə proqramlar yazın.

💻 Hissə 2 — Qurulum Tapşırıqları Sessiya 01 · 30 xal

Hər tapşırığın sonunda terminal çıxışının screenshot-unu müəllimə göndərin.

1

VirtualBox + Ubuntu qurulumunu tamamla Orta · 10 xal

VirtualBox-da Ubuntu 24.04 LTS VM yaradın və aşağıdakı əmrləri işlədərək screenshot çəkin:

# VM-in içindən bu əmrləri işlədin
uname -a
lsb_release -a
free -h
df -h
nproc

# Paketləri yenilə (screenshot lazımdır)
sudo apt update && sudo apt upgrade -y
★ AI Tip: Xəta alırsınızsa çıxışı kopyalayıb Claude-a yazın: "VirtualBox-da Ubuntu qurarkən bu xətanı alıram, həll yolu nədir?"
2

SSH bağlantısı qur (host → VM) Orta · 10 xal

VirtualBox NAT port forwarding istifadə edərək öz kompüterinizdən VM-ə SSH ilə qoşulun.

# VM-in içindən:
sudo apt install -y openssh-server
sudo systemctl enable ssh
sudo systemctl start ssh
sudo systemctl status ssh   ← screenshot bu əmrdən

# Host-dan (Mac Terminal / Windows PowerShell):
ssh -p 2222 SIZIN_ISTIFADECI@127.0.0.1
# Qoşulduqdan sonra:
hostname && whoami           ← screenshot bu əmrdən
3

AWS EC2 — Cloud Linux serveri yarat Çətin · 10 xal

AWS Free Tier hesabı açın, t2.micro EC2 instance yaradın və SSH ilə qoşulun.

# EC2-yə qoşulduqdan sonra bu əmrləri işlədin:
uname -a
lsb_release -a
curl http://169.254.169.254/latest/meta-data/public-ipv4
# Son iki əmr AWS metadata API-dir — yalnız EC2-də işləyir!

# Əsas alətləri qur
sudo apt update
sudo apt install -y git curl wget htop net-tools

# Bitirdikdən sonra mütləq STOP edin:
# AWS Console → Instance → Instance State → Stop
★ AI Tip: "AWS EC2-yə SSH edirəm amma 'Connection timed out' alıram. Security Group ayarlarını necə yoxlayım?" — Claude Security Group debug addımlarını verir.
📂 Hissə 3 — Linux Fayl Sistemi Tapşırıqları Sessiya 02 · 35 xal

Bu tapşırıqları Ubuntu VM-inizdə (VirtualBox və ya AWS EC2) icra edin. Hər tapşırıq üçün terminal çıxışını screenshot edin.

1

Fayl sistemi xəritəsini çıxar Asan · 5 xal

Aşağıdakı əmrləri işlədərək Linux fayl sistemini araşdırın:

# Root direktoriyasına get
cd /
pwd

# Bütün direktoriyaları listə al
ls -la /

# Ağac şəklində gör (əvvəlcə qur)
sudo apt install -y tree
tree / -L 1

# Cari istifadəçinin ev qovluğunu tap
echo $HOME
ls -la ~

Sual: ls -la / çıxışında ən çox hansı icazə formatını gördünüz? drwxr-xr-x nə deməkdir? Cavabınızı screenshot yanında yazın.

2

Sistem məlumatlarını doğru yerdən tap Asan · 10 xal

Hər məlumatı doğru direktoriyadan oxuyun:

# 1. Hostname-i /etc-dən oxu
cat /etc/hostname

# 2. Kernel versiyasını /proc-dan oxu
cat /proc/version

# 3. CPU məlumatını /proc-dan oxu
cat /proc/cpuinfo | grep "model name" | head -1

# 4. RAM məlumatını /proc-dan oxu
cat /proc/meminfo | grep -E "MemTotal|MemFree|MemAvailable"

# 5. Mövcud diskləri /dev-dən gör
ls /dev/sd* 2>/dev/null || ls /dev/vd* 2>/dev/null || echo "Virtual disk: /dev/sda mövcuddur"

# 6. Disk istifadəsini göstər
df -h /

# 7. Log fayllarının siyahısını gör
ls /var/log/
3

Doğru yerə fayl yarat Orta · 10 xal

Hər tapşırığı doğru direktoriyada icra edin:

# A — Öz home qovluğunuzda iş direktoriyası yarat
mkdir -p ~/dataops/scripts ~/dataops/data
cd ~/dataops
pwd    # /home/SIZIN_ADИНIZ/dataops çıxmalıdır

# B — Skript faylı yarat (home-da olmalıdır, /tmp-də deyil)
cat > ~/dataops/scripts/system-info.sh << 'EOF'
#!/bin/bash
echo "=== Sistem Məlumatları ==="
echo "Hostname: $(hostname)"
echo "OS: $(lsb_release -d | cut -f2)"
echo "Kernel: $(uname -r)"
echo "Uptime: $(uptime -p)"
echo "RAM: $(free -h | awk '/^Mem/{print $2}')"
echo "Disk: $(df -h / | awk 'NR==2{print $4}') boş"
EOF

# C — Skripti icra edilə et
chmod +x ~/dataops/scripts/system-info.sh

# D — İşlət
bash ~/dataops/scripts/system-info.sh
★ AI Tip: Skript xəta verirsə: "Bu bash skriptini çalışdıranda bu xətanı alıram: [xəta]. Səbəb nədir?"
4

Direktoriyaları fərqləndir — müsabiqə tapşırığı Çətin · 10 xal

Aşağıdakı sualların cavabını terminal əmrləri ilə tapın (sual-cavab şəklində yazın):

  • python3 proqramı hansı direktoriyadadır? (which əmrindən istifadə edin)
  • ls əmrinin tam yolu nədir? (which ls)
  • /bin vs /usr/bin — fərq varmı? (ls -la /bin ilə yoxlayın)
  • /etc-də neçə fayl/qovluq var? (ls /etc | wc -l)
  • /var/log-da ən böyük fayl hansıdır? (du -sh /var/log/* 2>/dev/null | sort -rh | head -5)
